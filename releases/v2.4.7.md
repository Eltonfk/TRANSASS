# v2.4.7 — Tradução multi-idioma funcionando ponta-a-ponta na web

Primeira release pública do Transass Web com o fluxo completo validado em
produção: **extração da faixa correta → tradução → karaokê → arquivo com
lineage → publicação**.

Evidência real (Paranoia Agent S01E01, francês → PT-BR): 243 eventos de
diálogo traduzidos e publicados a partir da faixa "French [Full]".

## Destaques

- **Tradução de qualquer idioma para PT-BR** com preservação de karaokê,
  seletor por temporada/episódio e detecção automática dos idiomas disponíveis.
- **Auto-classificação ANIME** ao usar uma pasta cujos vídeos têm ASS/SSA
  embutido (registra série + episódios na biblioteca).
- **Pipeline v2_3_0 na web**: primeira linha de execução real ponta-a-ponta
  pelo app (v2_3_8 permanece canônico; conexão live à web é trabalho futuro
  com gate próprio).

## Correções nesta versão

- Retradução instruída ao idioma errado: precedência agora é
  **ambiente por job → config global → inglês**, e a UI envia o idioma
  selecionado de cada episódio até o prompt do modelo.
- `NameError` no runner de retradução que derrubava toda execução (código 1).
- Escolha de faixa embutida: diálogo completo tem prioridade sobre faixas
  "Forced"/"Signs & Songs"; desempate determinístico.
- Seleção de episódios individuais ("seleção de episódios inválida").
- Badge de fonte reflete o idioma selecionado (+ endpoint `/source-status`).
- Caminho V226 honra `TRANSLATOR_SOURCE_LANGUAGE` sem contexto explícito.

## Qualidade

- 32 testes offline determinísticos cobrindo seleção, faixas, idiomas,
  retradução e auto-classificação.
- Fail-closed preservado: contenção de caminhos, pré-flight de retradução,
  versões antigas sempre preservadas, nada publicado sem validação.

## Notas operacionais

- Imagem Docker correspondente: `subtranslate:v2.4.7-*`.
- Pipeline ativo em produção: `TRANSLATOR_PIPELINE=v2_3_0`.
- Limitação conhecida: modelo local 9B pode deixar resíduo do idioma de
  origem em linhas difíceis; os flags de auditoria sinalizam os suspeitos.
