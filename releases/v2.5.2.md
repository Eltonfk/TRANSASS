# Transass v2.5.2

Esta versão fecha a rodada de higienização operacional e deixa o próximo
release rastreável: o código, a imagem Docker e os artefatos passam a carregar
versão e commit identificáveis, sem transformar o diretório de estado em uma
caixa-preta arqueológica.

## Destaques

- Rotina `transass_maintenance.py` para relatório e retenção segura de
  artefatos gerados pelo runtime.
- Dry-run como padrão; `--apply` explícito, proteção contra jobs ativos e
  bloqueio de caminhos fora do `state`.
- Dockerfile com metadados OCI de versão, revisão e origem do projeto.
- Testes determinísticos para retenção, preservação de acervo e segurança de
  alvos.
- Interface, documentação e instruções de operação alinhadas em 2.5.2.

## Operação

```sh
python3 scripts/transass_maintenance.py --state-dir /caminho/para/state --json
```

Faça backup antes de qualquer limpeza efetiva e aplique somente após conferir
o relatório:

```sh
python3 scripts/transass_maintenance.py --state-dir /caminho/para/state --apply
```

O comando não remove mídia, legendas publicadas, acervo, glossário, banco
SQLite ou configuração de transporte.

## Verificação

- suíte offline completa;
- testes determinísticos do Desktop e do módulo de manutenção;
- build Docker com rótulos OCI de versão e commit;
- smoke check de `/health` e `/version` após a atualização local.

O AppImage e o instalador Windows devem ser gerados pelo workflow nativo
`desktop.yml` a partir da tag `v2.5.2`; o `.exe` não é cross-buildável no Linux.
