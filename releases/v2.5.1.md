# Transass v2.5.1

Esta versão transforma o Desktop em uma entrega testável de ponta a ponta no
Linux e no Windows, além de consolidar as correções que estabilizaram tradução,
karaokê e monitoramento térmico.

## Destaques

- AppImage nativo: abre uma janela própria, sem sequestrar o navegador.
- Instalador Windows por usuário (`Transass-Setup-2.5.1.exe`).
- Thermal Guard com backoff, histerese e suporte a NVIDIA, AMD e Intel/fallback.
- Progresso atual, Caixa de entrada, Acervo e Revisão sincronizados novamente.
- Tradução de OP/ED baseada no conteúdo: inglês continua sendo inglês mesmo
  quando a etiqueta da faixa jura solenemente que é japonês.
- Correções de execução Qwen/DeepSeek sem fallback e de orçamento físico.
- Selos de versão/publicação no acervo.

## Artefatos

- `Transass-x86_64.AppImage`: Linux x86_64.
- `Transass-Setup-2.5.1.exe`: Windows x64.
- `SHA256SUMS`: hashes para verificação dos downloads.

Os bundles incluem `ffmpeg` e `ffprobe`. Modelos e chaves de API não são
embutidos; a configuração continua pertencendo ao usuário, como deve ser.

## Verificação

- suíte offline completa;
- suíte Desktop;
- smoke test do AppImage/bundle Linux;
- build, instalação silenciosa, inicialização, health check e desinstalação do
  instalador em runner Windows nativo.
